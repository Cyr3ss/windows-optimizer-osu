# Windows Gaming & Tablet Latency Optimizer (osu! Edition)

Набор скриптов автоматической настройки Windows, оптимизации графического планшета (**OpenTabletDriver / XP-Pen / Wacom / Huion**), устранения задержек ввода (Input Lag), оптимизации сети и безопасного деблоатинга фоновых служб Windows.

Создан специально для быстрого применения после переустановки Windows или на новом ПК.

---

## ⚡ Быстрый старт (В один клик)

1. Откройте **PowerShell от имени Администратора**:
   * Нажмите `Win + X` -> выберите **Терминал (Администратор)** или **PowerShell (Администратор)**.
2. Перейдите в папку с репозиторием и запустите мастер-скрипт:
   ```powershell
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   .\apply_all_tweaks.ps1
   ```

## 🛠️ Что делает каждый модуль

### 1. `01_grub_efi_cleanup.ps1` — Очистка загрузчика GRUB / Linux
* **Проблема:** После удаления Linux в скрытом системном разделе EFI и энергонезависимой памяти UEFI (NVRAM) остаются папки `grub`, `systemd`, `loader` и записи дистрибутива в меню BIOS.
* **Что делает скрипт:**
  * Монтирует скрытый системный раздел EFI (`S:`).
  * Безопасно удаляет папки `grub`, `loader`, `systemd`, `refind`, `Linux`, старые ядра и образы initramfs.
  * Синхронизирует `\EFI\BOOT\BOOTX64.EFI` со стандартным загрузчиком Windows (`bootmgfw.efi`).
  * Удаляет запись `Linux Boot Manager` из BCD NVRAM и ставит **Windows Boot Manager** первым в очереди загрузки.
  * Корректно отмонтирует раздел `S:`.

### 2. `02_tablet_pen_latency.ps1` — Оптимизация графического планшета
* **Проблема:** Windows по умолчанию накладывает 300 мс задержки на касание пера для ожидания жестов и эмуляции правого клика (Press-and-Hold), а также усыпляет USB порты.
* **Что делает скрипт:**
  * `HoldMode = 0` — отключает задержку «нажатие и удержание для правого клика».
  * `FlickMode = 0` — отключает буферизацию жестов пера (Flicks).
  * `Splash = 0` — отключает анимацию кругов/волн при нажатии.
  * `USB Selective Suspend = Disabled` — отключает энергосбережение USB-портов (планшет опрашивается непрерывно на максимальной частоте).
  * Отключает спящий режим для всех корневых USB-концентраторов (USB Root Hubs).

### 3. `03_gaming_system_latency.ps1` — Системные таймеры и Game Mode
* **Что делает скрипт:**
  * `bcdedit /set disabledynamictick yes` — отключает динамический пропуск тактов таймера CPU (исключает микрофризы фреймтайма).
  * `bcdedit /set useplatformclock no` — задействует быстрый аппаратный таймер TSC процессора вместо медленного HPET.
  * Включает **Windows Game Mode** (`AutoGameModeEnabled = 1`) для автоматического повышения приоритета игры.
  * Включает `HonorFSE` в `GameConfigStore` для прямого вывода кадров в обход композитора DWM.
  * Настраивает мультимедийный планировщик Windows (`SystemResponsiveness = 0`, `NetworkThrottlingIndex = 0xFFFFFFFF`) для отдачи 100% ресурсов активной игре.

### 4. `04_network_ping_tweaks.ps1` — Сеть и пинг
* **Что делает скрипт:**
  * Отключает **Алгоритм Нейгла (`TCPNoDelay = 1`, `TcpAckFrequency = 1`)** на всех активных сетевых адаптерах (убирает искусственную буферизацию мелких сетевых пакетов).
  * Отключает фоновую P2P-раздачу обновлений Windows (`DODownloadMode = 0`).

### 5. `05_debloat_services_tasks.ps1` — Фоновые службы и SSD
* **Что делает скрипт:**
  * Отключает телеметрию **`DiagTrack`** (Connected User Experiences and Telemetry).
  * Отключает **`SysMain` (Superfetch)** — избавляет SSD от постоянной скрытой фоновой записи и исключает спайки памяти.
  * Переводит службы **HP OEM / Support** (`HPAppHelperCap`, `HPDiagsCap`, `HPNetworkCap`, `HPSysInfoCap`) и **AnyDesk** в ручной режим.
  * Отключает тяжелые задачи планировщика:
    * `Microsoft Compatibility Appraiser` (фоновый сканер совместимости).
    * `Customer Experience / CEIP` (`Consolidator`, `UsbCeip`).
    * `DiskDiagnosticDataCollector`.
  * **Оптимизация SSD:** Включает `fsutil behavior set disablelastaccess 1` (Windows перестает обновлять дату последнего доступа к файлам при чтении).
  * **Отклик интерфейса:** Устанавливает `MenuShowDelay = 0` и `MinAnimate = 0` (мгновенное открытие меню и окон).

## 🎮 Рекомендованные настройки osu! и OpenTabletDriver

### OpenTabletDriver:
1. **Область экрана:** Задайте `1920 × 1080` (полный экран), если играете с Raw Input, либо сопоставьте соотношение сторон с активной областью планшета.
2. **Hovering (Перо в воздухе):** Если вы не касаетесь планшета при игре, в `Bindings` отключите действие на наконечник (`Tip Button -> None`).
3. **Фильтры:** По умолчанию держите фильтры выключенными (`Filters: []`) для минимальной задержки, либо используйте `Devocub Filter` с `Anticipate 5-10 ms` для компенсации заводского аппаратного сглаживания планшета.

### Настройки внутри osu!:
* **Ограничение частоты кадров:** `Без ограничений (в игре)` (Unlimited).
* **Полноэкранный режим:** `Включен`.
* **Уменьшать просадку кадров:** `Выключено`.
* **Змейка слайдеров, вспышки комбо, освещение попаданий:** `Выключено`.
* **Затемнение фона:** `100%`.
